**Image Zoom** scales the images on cards during review, leaving text at its normal size.

- `zoom_in_shortcuts`, `zoom_out_shortcuts`, `reset_shortcuts`: lists of key combinations. On macOS, `Ctrl` means the Command key. Both `=` and `+` are listed for zoom in so it works with or without Shift on most keyboards.
- `step`: how much each key press multiplies the zoom by (1.25 = 25% larger).
- `min_zoom`, `max_zoom`: the limits (1.0 = 100%).

Shortcut changes apply the next time you start reviewing. The current zoom level is remembered per profile.
